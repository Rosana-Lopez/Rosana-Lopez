## Projeto em destaque

### [Análise de Eficiência de Crédito Bancário](https://github.com/Rosana-Lopez/Analise-de-eficiencia-de-credito-bancario-)

> Sistema de análise operacional para concessão de crédito bancário com classificação de risco via ML, priorização inteligente de fila e simulação de impacto financeiro.

| Métrica | Manual | Automatizado |
|---|---|---|
| ⏱ Tempo de análise | 1.250h | 79,5h |
| 👥 Analistas | 53 | 4 |
| 📉 Perdas financeiras | R$ 52,1M | R$ 4,3M |
